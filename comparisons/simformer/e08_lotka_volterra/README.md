# E08 — Lotka–Volterra with unstructured observations

**Paper:** §4.2, Fig. 5.

## What they did

Four global parameters (growth, hunting, death rates), prior a sigmoid-transformed
normal scaled to [1, 3]; coupled ODEs integrated over time; Gaussian observation
noise σ = 0.1. **Inference on the full time series, not summary statistics** —
explicitly unlike Lueckmann et al. (2021). 10⁵ simulations, 8 transformer layers.

Two synthetic observation scenarios: (a) four irregularly-timed measurements of
the prey population only; (b) the same plus nine irregular predator
measurements. Both reduce to "most of the data tokens are missing", which the
condition mask handles natively. Posterior predictives are generated by sampling
the *data* conditional, without running the simulator. Quantitative panel:
Fig. 5c, C2ST against MCMC for the posterior and for arbitrary conditionals —
Simformer variants only, no external baseline.

## What we do

The interesting property for COMPASS is that "unstructured data" is just a
condition mask with holes, which COMPASS supports directly — but only if the
data tokens are *individually addressable*, i.e. one token per (species, time)
pair. That is the same design question `common/tasks.py` answers with `Atomic`
vs `IID` blocks, and it is worth doing deliberately rather than by default.

Existing code to draw on rather than rewrite:
- `tutorials/Population_Dynamics.py` — a Lotka–Volterra already in the repo.
- `Compositional_score_testing/Gauss_test/tasks.py::LotkaVolterraTask` — RK4
  integrator, prior transform, exact likelihood. Note its prior is mapped to a
  standard-normal latent for the Gaussian composition rules; **the paper's
  protocol is untransformed**, so do not reuse that part here.

## To build

1. `simulator.py` — the paper's parameterisation (sigmoid-normal prior scaled to
   [1,3], σ = 0.1 observation noise), a fixed dense time grid, and a mask
   builder for the two observation scenarios.
2. Decide the token layout for the time series and record the choice.
3. `run.py` — stages mirroring e01, with `deep=True` for the 8-layer variant.
4. Reference posteriors: the likelihood is exact given the ODE solution, so
   `common/reference.py` applies unchanged.

## Watch out for

- **Sequence length.** A dense time grid at one token per observation is where
  the quadratic attention cost starts to bite, and where COMPASS's
  key-padding convention starts to matter in the *other* direction: with most
  data conditioned, there are many keys and few latents.
- The paper subsamples time points during training (A1.2) to learn all
  finite-dimensional marginals. COMPASS has no subsampling; without it the model
  is tied to the training grid. Record this as a mismatch if the grid is fixed.
